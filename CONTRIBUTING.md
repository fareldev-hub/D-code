# Contributing Guide

Terima kasih sudah tertarik berkontribusi ke project ini! 🎉

Repo ini dikelola oleh 2 orang maintainer. Semua kontribusi—baik dari maintainer
maupun dari luar—wajib mengikuti aturan di bawah ini.

## 📋 Aturan Utama

1. **Dilarang push langsung ke `main`.** Semua perubahan harus melalui Pull Request.
2. **Minimal 1 approval** dari maintainer sebelum PR di-merge.
3. **Gunakan branch terpisah** untuk setiap fitur/perbaikan.
4. **Tulis commit message yang jelas** (lihat format di bawah).
5. **Jangan copy-paste kode berlisensi** tanpa mencantumkan sumber dan lisensinya.
